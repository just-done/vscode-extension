# Just.

For the business you are building with AI, Just Domain finds the name and Just Publish puts the website online. Just Domain shows which domain names are available and both prices, and links to register one on justdomain.ai. Searching needs no account. Just Publish puts your site live at a public link and changes it later; you sign in once. Nothing is bought in the chat. You register and pay on justdomain.ai.

## The two servers

This extension adds two hosted MCP servers to VS Code. Run **MCP: List Servers** to see them.

| Server | Address | Sign-in |
| --- | --- | --- |
| Just Domain. | `https://mcp.justdomain.ai/` | none |
| Just Publish. | `https://mcp.justpublish.ai/` | your Just account, in your browser, the first time |

Requires VS Code 1.101 or later.
